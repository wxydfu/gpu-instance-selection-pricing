## 腾讯云 GPU 服务器是什么，和自建 GPU 机器差在哪

它是按需租用的 GPU 算力，官方定义里主要面向深度学习训练与推理、图形图像处理、科学计算三类场景。和自建 GPU 服务器最实际的差别有三点：开机速度、现金流、以及驱动这类琐事由谁负责。

自建机器配置固定，想从 1 卡换到 8 卡得重新采购；云上只需要几分钟就能拿到一个或一批实例，配置可以一键升级。成本结构上，自建要先掏一笔硬件钱，还要承担高功耗改造和运维人力；云上是包月或按量付费，硬件跟着主流 GPU 更新，不用操心置换。

运维这块的差异比想象中大。腾讯云 GPU 实例和 CVM、CLB 等产品内网打通，同地域内网流量免费，登录不需要跳板机。自建则要自己装机、自己装驱动、自己搭跳板。安全上，不同用户的资源是隔离的，配合安全组和网络 ACL 可以控制进出实例和子网的流量。

性能口径上，官方给出的单机峰值是 125.6T Flops 单精度、62.4T Flops 双精度——注意这是整机数字，不是单卡，选型时别拿它跟单卡参数直接对比。

## 按用途选型号：训练、推理、渲染、科学计算

## 买之前建议先确认的五件事

这五项在购买页上都不显眼，但会直接影响后续使用：变配规则、驱动版本、库存、地域、备份。前两项决定你能不能顺利改主意，后三项决定出问题时有没有退路。

**1. 变配只能在同一实例族内进行。** PNV4、GT4、GN10X、GN10Xp、GN6、GN6S、GN7、GN8、GNV4v、GNV4、GN7vw、GI1 都支持同族调整配置，GI3X 不支持调整。换句话说，想把 T4 换成 V100，不能原地升级，只能重新购买实例再迁数据。规划时把这一点算进去。

**2. 驱动装错，机器起不来。** 物理直通实例拥有完整 GPU，可以用 Tesla 或 GRID 驱动，部分型号不支持 GRID；vGPU 实例没有完整 GPU，只能使用特定版本的 GRID 驱动。买 vGPU 或渲染实例时，购买页的“公共镜像”里有预装 GRID 驱动的选项，直接选它比事后折腾省事。普通 GPU 实例则支持 GPU 驱动、CUDA、cuDNN 的自动安装，也有预装驱动的镜像可选。

**3. GPU 资源会售罄。** 遇到售罄按顺序试：换地域、换可用区、改配置。这三个动作覆盖了绝大多数情况。

**4. 地域决定内网能不能通。** 同一地域的实例可以走内网，不同地域只能走公网并且计费。选地域时优先靠近终端用户，同时把数据所在的存储放在同一地域。

**5. 本地盘的数据要自己兜底。** 云硬盘可以靠自定义镜像和快照备份；本地盘只能做系统盘镜像，数据盘得自建备份策略。部分 CPM GPU 实例配了 NVMe SSD，读写性能是普通型号的三倍，跑高性能计算作业很稳，但速度快不等于有备份。存储选项本身有四类——云硬盘、本地盘、COS、块存储设备映射，价格和适用场景各不相同；CFS Turbo 可以弹性扩容量并保证三副本一致性，COS 配合 GooseFS 则能提升数据局部性和写入带宽。

## 开通一台 GPU 云服务器的实际流程

流程本身不复杂：选地域和实例族、选镜像、配存储和网络、确认计费方式，然后开通。几分钟内实例就能用，麻烦的是每一步里的选项。

1. **选地域和可用区。** 靠近用户，且和其他资源同地域。
2. **选实例族。** 按上一节的场景对应关系来，别只看价格。
3. **选镜像。** 公共镜像、共享镜像、自定义镜像三类。vGPU 和渲染实例挑预装 GRID 驱动的公共镜像；其他实例可以用自动安装驱动的方案。
4. **配存储和网络。** 系统盘、数据盘选云硬盘还是本地盘，公网 IP 还是弹性公网 IP（EIP），安全组怎么放行。
5. **确认计费方式。** 按量、包月或竞价，确认后开通。

软件层还有几个能省事的工具：TACO Kit 是腾讯云自研的计算加速引擎，其中 TACO Infer 做推理加速，提供一行优化接口，不改变原有部署方式，支持多种框架模型和硬件，能跑在云服务器、物理机、容器里；TCCL 面向训练加速；qGPU 做 GPU 共享；弹性 RDMA 网卡用于提升网络性能。镜像中心里有面向 AIGC、计算机视觉、自然语言处理、数据科学的容器镜像，可以通过 HAI、HCC、CVM、TKE 拉取。

## 常见问题

**腾讯云 GPU 服务器多少钱一小时？**
公开示例价：GN7（1×T4，8 核 32GB）$0.204/小时，GN7vw（1×T4，16 核 64GB）$0.242/小时，GN10Xp（8×V100 32GB）$23.54/小时，均为国际站按量价格。国内站以人民币计价，地域和配置都会影响最终数字。

**按量计费还是包月划算？**
短时任务和临时验证用按量，按秒计费不浪费；长期稳定运行选包月。判断方法很朴素：按量单价乘以预计运行小时数，再和包月报价对比。

**能中途升级配置吗？**
可以，但仅限同一实例族内调整，GI3X 不支持调整。跨代换卡需要重新购买实例。

**资源售罄了怎么办？**
依次尝试更换地域、更换可用区、更改资源配置。

**需要自己装显卡驱动吗？**
不一定。GPU 驱动、CUDA、cuDNN 支持自动安装，也有预装驱动的镜像；vGPU 实例需要匹配特定版本的 GRID 驱动。

**GPU 实例能当普通云服务器用吗？**
可以，管理方式和 CVM 一致，能与 CVM、CLB 等产品内网互通，同地域内网流量免费。
